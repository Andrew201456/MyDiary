# MyDiary 🌸

Ιδιωτικό ημερολόγιο περιόδου, κύκλου και καθημερινής ευεξίας — browser-based PWA για Cloudflare Workers.

- Ελληνικό, mobile-first UI (Σήμερα · Ημερολόγιο · + Καταχώρηση · Υπενθυμίσεις · Αναφορά)
- Καταγραφή περιόδου, διάθεσης, συμπτωμάτων, ύπνου, θερμοκρασίας, βάρους, νερού, τεστ ωορρηξίας, σεξουαλικής ζωής και σημειώσεων
- Προαιρετική καταχώρηση **ολόκληρης περιόδου πολλών ημερών** (όσα ορίζονται στις Ρυθμίσεις), χωρίς αντικατάσταση άλλων πεδίων σε ήδη υπάρχουσες ημερήσιες εγγραφές
- Ημερολόγιο και ενδεικτικές προβλέψεις με βάση τις ιστορικές καταχωρήσεις
- Αναφορές, ρυθμίσεις διάρκειας κύκλου, τοπικές υπενθυμίσεις
- Εξαγωγή/εισαγωγή JSON, πλήρης διαγραφή δεδομένων
- **Online:** username/password, Cloudflare D1, συγχρονισμός μεταξύ κινητών και υπολογιστών. Ο browser κρυπτογραφεί τις εγγραφές με AES-GCM **πριν** την αποθήκευσή τους στη βάση.
- **Εισαγωγή αρχικού Period Calendar .fpc:** επιλέγεις το backup από τις Ρυθμίσεις και το app το μετατρέπει τοπικά χωρίς ανάγνωση των παλιών account/password πεδίων.

## Online ρύθμιση Cloudflare — ΑΠΑΡΑΙΤΗΤΗ

**Η βάση Cloudflare D1 δεν δημιουργείται αυτόματα από GitHub commit.** Το repository περιλαμβάνει Worker API, SQL schema και UI, αλλά η πραγματική βάση πρέπει να δημιουργηθεί στο δικό σου Cloudflare account. Δεν πρέπει να χρησιμοποιείται το app για πραγματικά δεδομένα πριν ολοκληρωθεί η ρύθμιση και οι έλεγχοι.

Από τον φάκελο του `MyDiary` (Windows PowerShell ή terminal), αφού συνδεθείς με `npx wrangler login`:

1. `npm install`
2. `npx wrangler d1 create mydiary-db` — κράτησε το **database_id (UUID)** που θα εμφανιστεί.
3. Άνοιξε το `wrangler.jsonc` και αντικατάστησε **μόνο** το `REPLACE_WITH_YOUR_D1_DATABASE_ID` με αυτό το UUID.
4. `npx wrangler d1 execute mydiary-db --remote --file=./schema.sql` — δημιουργεί τους πίνακες χρηστών, συνεδριών, κρυπτογραφημένου ιστορικού και αποτυχημένων login.
5. `npx wrangler secret put MYDIARY_SIGNUP_CODE` — πρόσθεσε έναν **δικό σου τυχαίο κωδικό δημιουργίας λογαριασμών τουλάχιστον 12 χαρακτήρων**, ο οποίος χρησιμοποιείται μόνο για να επιτρέπεις νέες εγγραφές. **Ποτέ** μην τον ανεβάζεις στο GitHub ή στο chat.
6. `npx wrangler deploy` — δημοσιεύει τον Worker μαζί με το frontend.

Έπειτα άνοιξε το `https://mydiary.<το-workers-subdomain>.workers.dev`, επέλεξε **Νέος λογαριασμός**, φτιάξε username και **διαφορετικό** password τουλάχιστον 12 χαρακτήρων και συμπλήρωσε τον signup κωδικό.

Στο **Μενού → Ρυθμίσεις → Εισαγωγή Period Calendar .fpc ή JSON**, διάλεξε το αρχείο σου. Δες τον αριθμό των παλιών εγγραφών, επιβεβαίωσε την εισαγωγή και **περίμενε να εμφανιστεί «Αποθηκεύτηκε στο Cloudflare ✓»**. Στη δεύτερη συσκευή συνδέσου με τα ίδια στοιχεία και κάνε **Έλεγχος συγχρονισμού**.

Αν το GitHub είναι ήδη συνδεδεμένο με αυτόματο Cloudflare deployment, ο χειροκίνητος `wrangler deploy` μπορεί να χρειάζεται μόνο στην πρώτη ρύθμιση. Το **Cloudflare secret** και το πραγματικό **D1 database_id** παραμένουν υποχρεωτικά.

Για τοπική ανάπτυξη: `npm run dev` αφού βάλεις έγκυρο database_id στο Wrangler config. Το `--remote` στο βήμα δημιουργίας πινάκων αφορά μόνο την cloud βάση — **μην** το αφαιρείς αν θέλεις πραγματικό online συγχρονισμό.

## Τι περιλαμβάνει η πρώτη έκδοση

- **Σήμερα:** επόμενη ενδεικτική περίοδος, μέσοι όροι κύκλου και διάρκειας, πρόσφατες εγγραφές
- **Ημερολόγιο:** μηνιαία προβολή με καταγεγραμμένες ημέρες περιόδου, εκτιμώμενες επόμενες ημέρες και προσεγγιστικό γόνιμο διάστημα
- **+ Προσθήκη:** περίοδος/ροή, συμπτώματα, διάθεση, θερμοκρασία, βάρος, ύπνος, νερό, σεξουαλική ζωή, τεστ ωορρηξίας, αυτοεξέταση μαστού και σημειώσεις
- **Υπενθυμίσεις:** επόμενη περίοδος και νερό, με ειδοποιήσεις **μόνο όσο η εφαρμογή είναι ενεργή**
- **Αναφορά:** πλακίδια κατηγοριών, ιστορικό καταχωρήσεων και γραφήματα μετρήσεων
- **Μενού → Ρυθμίσεις:** διάρκεια κύκλου/περιόδου, εξαγωγή JSON, επαναφορά από JSON με προειδοποίηση αντικατάστασης και πλήρης διαγραφή με διπλή επιβεβαίωση

Τα εικονίδια και η υλοποίηση είναι πρωτότυπα. Πρόκειται για πρώτη λειτουργική προσέγγιση των screenshots και όχι αντιγραφή όλου του εμπορικού Android app. Δεν διαθέτει ακόμη σύνδεση Google, widgets, εγκυμοσύνη ή πραγματικές push ειδοποιήσεις όταν η εφαρμογή είναι κλειστή.

**Ασφάλεια δεδομένων:** Στο Cloudflare D1 αποθηκεύεται **μόνο κρυπτογραφημένο περιεχόμενο** ημερολογίου. Κάθε password ελέγχεται μέσω salted PBKDF2 και η κρυπτογράφηση γίνεται στον browser με PBKDF2-SHA256 και AES-GCM. Το κλειδί αποκρυπτογράφησης δεν αποθηκεύεται μόνιμα και η εφαρμογή ζητά login σε νέα επίσκεψη. Οι εκκρεμείς offline αλλαγές διατηρούνται μόνο ως **κρυπτογραφημένο** τοπικό αντίγραφο, που μπορεί να εξαχθεί σε JSON εφόσον συνδεθείς. Οι αιτήσεις /api/ **δεν** μπαίνουν σε service-worker cache. Σε conflict (HTTP 409) ο Worker δεν αντικαθιστά νεότερο cloud ιστορικό.

**Αν ξεχάσεις το password, δεν υπάρχει δυνατότητα αποκρυπτογράφησης του cloud ιστορικού** χωρίς προηγούμενο προσωπικό backup. Μην αφήνεις το app ανοιχτό σε κοινόχρηστες ή ξεκλείδωτες συσκευές. Τα JSON exports είναι **μη κρυπτογραφημένα** και πρέπει να φυλάσσονται με προσοχή.

**Παλιά .fpc:** ο importer διαβάζει μόνο `1.period` και `1.note`, παραλείποντας ολόκληρη την `1.user` με τα παλιά στοιχεία σύνδεσης. Από το παρεχόμενο backup αναγνωρίστηκαν **97 εγγραφές κύκλου και 28 ημερήσιες**. Για τις **84 εγγραφές με αρνητική διάρκεια** χρησιμοποιείται *ενδεικτικά* η απόλυτη τιμή (συνήθως τέσσερις ημέρες) και διατηρείται το αρχικό πρόσημο στο κρυπτογραφημένο provenance, ώστε να μπορείς να ελέγξεις τις ημερομηνίες. Το αρχείο δεν ανεβαίνει στο δημόσιο repository.

## Δημοσίευση από GitHub στο Cloudflare

Στο Cloudflare Dashboard → **Workers & Pages → Create application → Import a repository** επίλεξε `Andrew201456/MyDiary`. Το repository έχει **Workers API + static assets + D1 binding**. Πριν το πρώτο επιτυχημένο deployment πρέπει να έχεις δημιουργήσει D1, αντικαταστήσει το placeholder UUID στο `wrangler.jsonc` και ρυθμίσει το Secret `MYDIARY_SIGNUP_CODE`. Το deploy command είναι `npx wrangler deploy`. **Το commit από μόνο του δεν δημιουργεί database ή ολοκληρωμένη online εφαρμογή.**

Η εγκατάσταση PWA από Android Chrome γίνεται μέσω «Εγκατάσταση εφαρμογής» στο μενού του browser. Σε iPhone γίνεται μέσω Safari → Κοινοποίηση → Προσθήκη στην Αρχική οθόνη.

**Δοκιμές κώδικα:** `npm test` (Node.js 20+). Για live smoke test, δες `/api/health` αφού δημοσιευθεί.

## Προσοχή

Οι προβλέψεις ωορρηξίας και γόνιμων ημερών είναι ενδεικτικές. **Δεν αποτελούν αντισύλληψη, διάγνωση ή ιατρική σύσταση.** Το Cloudflare κρατά κρυπτογραφημένο αντίγραφο, αλλά η ανάκτηση προϋποθέτει τον σωστό κωδικό, οπότε χρησιμοποίησε και την εξαγωγή αντιγράφου. Οι ειδοποιήσεις υπενθυμίσεων σε αυτή την PWA λειτουργούν μόνο όσο η εφαρμογή είναι ανοιχτή. Για ειδοποιήσεις όταν είναι κλειστή χρειάζεται επιπλέον push υποδομή και άδεια χρήστη.
