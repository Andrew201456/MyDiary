# MyDiary 🌸

Ιδιωτικό ημερολόγιο περιόδου, κύκλου και καθημερινής ευεξίας — browser-based PWA για Cloudflare Workers.

- Ελληνικό, mobile-first UI (Σήμερα · Ημερολόγιο · + Καταχώρηση · Υπενθυμίσεις · Αναφορά)
- Καταγραφή περιόδου, διάθεσης, συμπτωμάτων, ύπνου, θερμοκρασίας, βάρους, νερού, τεστ ωορρηξίας, σεξουαλικής ζωής και σημειώσεων
- Προαιρετική καταχώρηση **ολόκληρης περιόδου πολλών ημερών** (όσα ορίζονται στις Ρυθμίσεις), χωρίς αντικατάσταση άλλων πεδίων σε ήδη υπάρχουσες ημερήσιες εγγραφές
- Ημερολόγιο και ενδεικτικές προβλέψεις με βάση τις ιστορικές καταχωρήσεις
- Αναφορές, ρυθμίσεις διάρκειας κύκλου, τοπικές υπενθυμίσεις
- Εξαγωγή/εισαγωγή JSON, πλήρης διαγραφή δεδομένων
- **Local-first:** τα δεδομένα υγείας αποθηκεύονται μόνο στον συγκεκριμένο browser. Δεν υπάρχουν λογαριασμοί ή αποθήκευση προσωπικών δεδομένων στο Cloudflare.

## Εκκίνηση / Cloudflare

```bash
npm install
npm run dev
```

Για δημοσίευση σε Cloudflare Workers (με σύνδεση στο ίδιο GitHub repo):

```bash
npx wrangler deploy
```

Η ρύθμιση `wrangler.jsonc` δημοσιεύει το directory `public/` ως static assets. Δεν χρειάζεται Worker database, secret ή Cloudflare AI binding.

## Τι περιλαμβάνει η πρώτη έκδοση

- **Σήμερα:** επόμενη ενδεικτική περίοδος, μέσοι όροι κύκλου και διάρκειας, πρόσφατες εγγραφές
- **Ημερολόγιο:** μηνιαία προβολή με καταγεγραμμένες ημέρες περιόδου, εκτιμώμενες επόμενες ημέρες και προσεγγιστικό γόνιμο διάστημα
- **+ Προσθήκη:** περίοδος/ροή, συμπτώματα, διάθεση, θερμοκρασία, βάρος, ύπνος, νερό, σεξουαλική ζωή, τεστ ωορρηξίας, αυτοεξέταση μαστού και σημειώσεις
- **Υπενθυμίσεις:** επόμενη περίοδος και νερό, με ειδοποιήσεις **μόνο όσο η εφαρμογή είναι ενεργή**
- **Αναφορά:** πλακίδια κατηγοριών, ιστορικό καταχωρήσεων και γραφήματα μετρήσεων
- **Μενού → Ρυθμίσεις:** διάρκεια κύκλου/περιόδου, εξαγωγή JSON, επαναφορά από JSON με προειδοποίηση αντικατάστασης και πλήρης διαγραφή με διπλή επιβεβαίωση

Τα εικονίδια και η υλοποίηση είναι πρωτότυπα. Η παρούσα έκδοση είναι **η πρώτη λειτουργική προσέγγιση** της εφαρμογής των screenshots και όχι ένα προς ένα αντίγραφο κάθε επιλογής ή όλων των λειτουργιών του Android app. Δεν έχει ακόμα cloud sync ή account login, σύνδεση Google, wearable widgets, εγκυμοσύνη, ειδοποιήσεις push στο παρασκήνιο ή πλήρη βιβλιοθήκη συμπτωμάτων.

**Προστασία ευαίσθητων δεδομένων:** Η εφαρμογή χρησιμοποιεί `localStorage` χωρίς κρυπτογράφηση σε επίπεδο εφαρμογής. Όποιος έχει πρόσβαση στο ξεκλείδωτο προφίλ browser/συσκευή μπορεί ενδεχομένως να διαβάσει τις καταχωρήσεις. Δεν πρέπει να χρησιμοποιείται σε κοινόχρηστη συσκευή χωρίς πρόσθετη προστασία. Το Cloudflare φιλοξενεί μόνο τα στατικά αρχεία της εφαρμογής και **δεν** αποθηκεύει τις προσωπικές εγγραφές.

## Δημοσίευση από GitHub στο Cloudflare

Στο Cloudflare Dashboard → **Workers & Pages → Create application → Import a repository** επίλεξε `Andrew201456/MyDiary`. Χρησιμοποίησε το `wrangler.jsonc` του project (static-assets-only Worker), με **Deploy command** `npx wrangler deploy`. Δεν χρειάζεται build output, database ή secret. Αν το Cloudflare ζητήσει build command, μπορεί να μείνει κενό ή να χρησιμοποιηθεί `npm install`, ανάλογα με το περιβάλλον του Git integration. Έλεγξε το πρώτο επιτυχημένο production deployment προτού δοκιμάσεις.

Η εγκατάσταση PWA από Android Chrome γίνεται μέσω «Εγκατάσταση εφαρμογής» στο μενού του browser. Σε iPhone γίνεται μέσω Safari → Κοινοποίηση → Προσθήκη στην Αρχική οθόνη.

**Δοκιμές κώδικα:** `npm test` (Node.js 20+).

## Προσοχή

Οι προβλέψεις ωορρηξίας και γόνιμων ημερών είναι ενδεικτικές. **Δεν αποτελούν αντισύλληψη, διάγνωση ή ιατρική σύσταση.** Η διαγραφή δεδομένων browser/PWA μπορεί να διαγράψει τις καταχωρήσεις: χρησιμοποίησε την εξαγωγή αντιγράφου. Οι ειδοποιήσεις υπενθυμίσεων σε αυτή την PWA λειτουργούν μόνο όσο η εφαρμογή είναι ανοιχτή. Για ειδοποιήσεις όταν είναι κλειστή χρειάζεται επιπλέον push υποδομή και άδεια χρήστη.

## Προέλευση

Ανεξάρτητη υλοποίηση εμπνευσμένη από λειτουργικά μοτίβα ημερολογίων κύκλου και τα screenshots αναφοράς που παρείχε ο χρήστης. Δεν περιλαμβάνονται κώδικας, σήματα, εικόνες ή αρχεία από τρίτη εφαρμογή.
